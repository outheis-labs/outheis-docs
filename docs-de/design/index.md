# Design

*Wie outheis gestaltet ist — Prinzipien, Struktur und die Überlegungen hinter der Architektur.*

---

Der Design-Abschnitt verbindet Theorie und Implementierung. Er beginnt mit einer konkreten Beobachtung — dass Multi-Agenten-KI-Systeme dieselben Koordinationsprobleme haben, die Betriebssysteme vor Jahrzehnten gelöst haben — und folgt diesem Faden durch Architektur, Datenformate, Agentenkommunikation und Speicher.

Das Ergebnis ist ein System, das auf expliziter Struktur, klarer Verantwortung und einer scharfen Grenze zwischen Code und Sprachmodell aufbaut.
